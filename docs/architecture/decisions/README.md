# Architecture decision records

Store significant, durable technical decisions in this directory. Read existing
ADRs before proposing a new one.

Copy [`000-template.md`](000-template.md) to a new sequentially numbered file
and use a short kebab-case title. Record the status as `Proposed` until the human
owner approves the decision. Update it to `Accepted` only after that approval;
use `Superseded` when a later accepted ADR replaces it.

ADRs document technical context and tradeoffs. They do not create or replace a
product PRD, roadmap, or human approval.
